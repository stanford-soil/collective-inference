# Collective inference depends on the communication channel

Code, data and analyses for "Collective inference depends on the communication channel" (J R Soc Interface, rsif-2026-0337, revised 2026). One pipeline reproduces every result in the revised paper from the raw data in `data/`.

## Running everything

```
bash run_all.sh            # full pipeline, about 45 minutes
SKIP_FIT=1 bash run_all.sh # about 6 minutes; skips models/01_fit.py and uses the committed models/fit_results.csv
```

`run_all.sh` runs each script from its own folder, in the order listed below, and saves each script's printed output to `logs/<folder>__<script>.log`. Every script can also be run on its own from its folder (for example `cd exp1 && Rscript 01_models.R`) once the steps before it have run. Run under a UTF-8 locale (`run_all.sh` sets `LC_ALL=C.UTF-8`); the critter counts are parsed from emoji.

Slow steps: `models/01_fit.py` (about 40 minutes), `figures/fig7_model_predictions.py` (about 1 minute), `partner_schedule/09_first_encounter.R` and `response_letter/01_exp1_old_vs_new.R` (1 to 2 minutes each). Everything else takes seconds.

Requirements: R with tidyverse, lme4, lmerTest, emmeans, broom.mixed, tidyboot, ggthemes, patchwork and jsonlite; Python 3 with pandas, numpy, scipy, statsmodels, scikit-learn and matplotlib.

## Condition labels

The data and code use the original condition names. The revised manuscript uses names that describe what participants experienced. `lib/common.R` and `lib/common.py` hold both.

| In data and code | In the revised manuscript |
|---|---|
| `interactive` | real-time messaging |
| `unidirectional` | delayed messaging |
| `slider` | numerical estimates (slider) |

## Corrections in the revision

1. **Partner assignment.** The experiments were designed to pair participants every round. The recipient rule in `experiments/server/src/callbacks.js` (`otherPlayers[(i + round) % 3]`) produced mutual pairs only in rounds 1, 4, 7 and 10 (Experiment 1) and 1, 4, 7 (Experiment 2). In other rounds, each participant sent to one network member and received from another. See `partner_schedule/`.
2. **Slider messages in Experiment 2.** All Experiment 2 analyses use only the `SR` networks, in both conditions (`lib/exp2_sr_games.csv`); the `RS` networks are excluded because their slider messages were inverted and their error was higher in both conditions. In the `RS_slider` treatment the slider value is the squirrel share, but the generated message reads "I think the population is X% rabbits" (`experiments/client/src/components/Opinion.jsx`), so received messages stated the complement of the sender's estimate. Participants' own estimates are scored correctly. The restriction is applied when the data are loaded (`lib/exp2_data.R` for R, `common.filter_exp2` in `lib/common.py`); `prep/03_exp2_clean.R` checks that the list matches the `SR_` treatments. Set `SUBSET=RS` or `SUBSET=ALL` to rerun an Experiment 2 script on other networks.
3. **Model timing.** In the message conditions the chat precedes the round's estimate, so `models/01_fit.py` now uses the sender from the same round (the original code used the previous round's sender). `models/02_timing_variants.py` compares the original and corrected timing.

| Script | Results |
|---|---|
| `01_agreement.py` | Agreement of the second coder with the original codes (Cohen's kappa by code; own counts kappa = .91, others' counts kappa = .86) |
| `02_apply_rules.py` | Applies adjudication rules A and B and lists the remaining disagreements |
| `03_merge_final.py` | `exp2_message_codes_final.csv`: original, second and final code of every message, with how each disagreement was resolved |
| `04_content_analysis.R` | Share of messages relaying social information and final-round error, with the original and the final codes (final codes, SR networks: b = -1.60, p = .031; `SUBSET=ALL`: b = -0.76, p = .094) |
| `05_count_reports_auto.py` | Automated detector of messages that report counts, validated against the final codes (SR: sensitivity .96, specificity .91, kappa = .83) and applied to Experiment 1 messages (real-time 81%, delayed 90%) and to the Experiment 2 chat networks missing from the original coding file | printed |
