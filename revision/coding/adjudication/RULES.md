# Adjudication rules

These rules were set by the adjudicator after the second coding and applied to the disagreements between coders.

A. A speaker's own estimate of the population ("I think 75% rabbits", "more rabbits") is **pb**. The social codes are reserved for content attributed to other players or to the group's pooled data.

B. A question appended to a report ("I see 2 rabbits, you?") adds **q**.

C. A message saying the speaker's window is unchanged ("same", "same as before", "no change") takes the code of the speaker's most recent earlier description of their own window: **pn** if they had given counts, **pb** if they had described it qualitatively, **o** if they had not yet described it.

D. Each message is coded for what the speaker meant, read in the context visible to the speaker (their own earlier messages and the messages sent to them), not for what the recipient could understand. Fragments that continue the speaker's previous message (for example a bare "?") are coded for what they add.

The remaining disagreements were resolved by the senior author, who reviewed each disputed message in the context visible to its sender without knowing which coder had assigned which coding.
