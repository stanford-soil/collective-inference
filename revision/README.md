# Revision analyses (J R Soc Interface, rsif-2026-0337)

This folder contains the analyses added for the 2026 revision of "Collective inference depends on the communication channel." Each script is run from its own folder. Scripts that use the cleaned data expect `analysis/exp1/exp1_clean_data.csv` and `analysis/exp2/exp2_clean_data.csv`, which are generated by the analysis notebooks in `analysis/` (they are not committed). The Experiment 2 cleaning notebook must be run under a UTF-8 locale.

## Condition labels

The data and code use the original condition names. The revised manuscript uses names that describe what participants experienced:

| In data and code | In the revised manuscript |
|---|---|
| `interactive` | real-time messaging |
| `unidirectional` | delayed messaging |
| `slider` | numerical estimates (slider) |

## Corrections reported in the revision

1. **Partner assignment.** The experiments were designed to pair participants every round. The recipient rule in `experiments/server/src/callbacks.js` (`otherPlayers[(i + round) % 3]`) produced mutual pairs only in rounds 1, 4, 7 and 10 (Experiment 1) and 1, 4, 7 (Experiment 2). In other rounds, each participant sent to one network member and received from another. See `partner_schedule/`.
2. **Slider messages in Experiment 2.** In the `RS_slider` treatment the slider value is the squirrel share, but the generated message reads "I think the population is X% rabbits" (`experiments/client/src/components/Opinion.jsx`), so received messages stated the complement of the sender's estimate. Participants' own estimates are scored correctly. See `exp2_sr_primary/`.
3. **Model timing.** `models/fit.py` now uses the sender from the same round for the message conditions, where the chat precedes the estimate. See `model_timing/`.

## Contents

- `exp1_reanalysis/`: Experiment 1 models refit with network-level random intercepts (`02_refit_network_RE.R`), attrition by condition for both experiments (`03_attrition.R`), complete-network robustness, and the exclusion-threshold table. `00_prep_exp1.R` prepares the data; `01_reproduce.R` checks that the original numbers reproduce. CSV files are the outputs.
- `exp2_sr_primary/`: Experiment 2 models on all games, on the unaffected `SR` games (primary in the revision), and on `RS` games, plus the full sample with slider direction as a covariate. `prep.R` is the data preparation from `analysis/exp2/exp2_main_analysis.qmd`, with an optional `SUBSET` environment variable (`SR` or `RS`). Run `models.R` with `SUBSET=` unset, `SR`, and `RS`.
- `partner_schedule/`: reconstruction of who sent to whom from the raw logs (`exp1.py`, `load1.py`, `load2.py`, `build.py`, `sched.py`, `sched_structure.py`, `exp1_ring.py`); per-round partner tables (`exp1_partners.csv`, `exp2_partners_playerround.csv`); a test of whose information moved estimates in one-way rounds (`influence_test.py`); the comparison of mutual and one-way rounds (`prep_mutual_vs_oneway.py`, then `mutual_vs_oneway.R`); same-round relaying (`relay.py`); and apparent question-answer coherence in one-way rounds (`coherence.py`).
- `coding/`: second coding of the Experiment 2 messages. `codebook.md` is the codebook given to the second coder; `unique_texts.csv` and `out_*.csv` are the second coder's labels for each unique message text (blind to the original codes); `agree.py` computes agreement with the original codes; `rules.py` applies the two adjudication rules (a speaker's own population estimate is `pb`; a trailing question adds `q`) and lists the remaining disagreements; `truechat.py` attaches the true sender, recipient and time from the raw logs. The adjudicated final codes will be added when adjudication is complete.
- `model_timing/`: `refit_timing_variants.py` fits the Belief and Evidence models under the original timing, the corrected timing, and alternative codings; `all_fits.csv` and `delta_aic.csv` are its outputs. `models/fit.py` and `models/fit_results.csv` contain the corrected version.
